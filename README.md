## 🛠️ How to Run

Each solution file can be run using Python 3:

```bash
python dayXX.py
```

Replace `XX` with the day number, for example: `python day08.py`.

---

## 📥 Input Instructions

Each script reads input from a file called:

```
input.txt
```
This file should be in the same directory of the script
But you don't need to rename all your inputs.
